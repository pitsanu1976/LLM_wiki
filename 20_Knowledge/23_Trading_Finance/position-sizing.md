# Position Sizing

**หลักการ:** กำหนด **จำนวนเงินที่ยอมเสีย** ก่อนซื้อ แล้วคำนวณขนาดไม้ย้อนกลับมา
ไม่ใช่เลือกจำนวนหุ้นที่อยากซื้อแล้วค่อยไปหาจุดตัดขาดทุน

## สูตร

```
เงินที่ยอมเสียต่อไม้ = เงินทุน × % ความเสี่ยงต่อไม้
ขนาดไม้ (หุ้น)      = เงินที่ยอมเสียต่อไม้ ÷ (ราคาเข้า − ราคาตัดขาดทุน)
```

## ตัวอย่าง (ตัวเลขสมมติเพื่ออธิบาย ไม่ใช่คำแนะนำ)

พอร์ต 100,000 บาท ยอมเสี่ยง 1% ต่อไม้ = 1,000 บาท
ซื้อที่ 25.00 ตัดขาดทุนที่ 23.00 (ห่าง 2.00 บาท/หุ้น)

```
ขนาดไม้   = 1,000 ÷ 2.00 = 500 หุ้น
เงินที่ใช้ = 500 × 25.00 = 12,500 บาท  (12.5% ของพอร์ต)
```

จุดสำคัญ: **stop loss กว้างขึ้น → ขนาดไม้ต้องเล็กลง** เงินที่ใช้จึงลดตาม
พูดอีกแบบ: ระยะตัดขาดทุนคือตัวกำหนดขนาดไม้ ไม่ใช่ความมั่นใจในหุ้น

## กฎจัดสรรจากบทความ SET

- ต่อหุ้น 1 ตัว ใช้เงิน **10–25%** ของพอร์ต
- พอร์ต 100,000 บาท → 10,000–25,000 บาทต่อตัว
- เหตุผล: กระจายความเสี่ยง + เหลือเงินซื้อตัวอื่นหรือเพิ่มตัวเดิม

> [!warning] กับดักที่พบบ่อย
> 10–25% เป็น **เพดานเงินลงทุน** ไม่ใช่ **เพดานความเสี่ยง**
> ถ้า stop loss กว้าง 20% ไม้ที่ใช้ 25% ของพอร์ตจะเสี่ยง 5% ของพอร์ตทันที
> ต้องคำนวณสองชั้น: เพดานเงิน **และ** เพดานความเสี่ยง
