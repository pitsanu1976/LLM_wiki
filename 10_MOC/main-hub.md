## วิธีใช้ vault นี้

1. **จับของได้ → โยนลง `00_Inbox/` ทันที** อย่าคิดตอนจับ
2. **ภายใน 7 วัน** → แยกเป็น atomic note แล้วย้ายเข้าโฟลเดอร์ที่ถูก
3. **ทุก note ต้องลิงก์เข้า MOC อย่างน้อย 1 ตัว** ไม่งั้น graph จะลอย
4. **หนึ่ง note = หนึ่งความคิด** — ถ้าชื่อต้องมี "และ" ให้แยก

## กติกาหลัก (อ่านฉบับเต็มที่ [[wiki-formatting-guide]])

- ทุก note มี YAML frontmatter 5 ฟิลด์บังคับ: `title`, `type`, `status`, `created`, `updated`
- ลิงก์ด้วย `[[ชื่อ note]]` ไม่ต้องใส่ path
- ตัวเลขทุกตัวต้องมีหน่วยและวันที่กำกับ
- โฟลเดอร์ = โดเมน / tag = มุมตัดขวาง / link = ความสัมพันธ์
